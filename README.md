## 📖 نبذة عن المشروع (Overview)

هذا المشروع مخصص لأصحاب المواقع ومنصات مشاركة الملفات الذين يحتاجون إلى صفحة وسطية آمنة (Redirect Page) لتوجيه الزوار للرابط النهائي بعد عداد تنازلي زمني. يتيح النظام للمدير إنشاء الروابط عبر أداة التوليد بسهولة مع إمكانية تشفير الروابط لحمايتها، تخصيص نصوص الأزرار، والتحكم بمدة الانتظار.

---

## ✨ المميزات والخصائص التقنية (Key Features)

* ⚡ **توليد روابط مخصص:** تحديد رابط الهدف، نص الزر، ومدة العداد بدقة عبر واجهة مستخدم سلسة وعصرية.
* 🔒 **تشفير Base64 المتقدم:** إخفاء وتشفير الروابط الأصلية لمنع برامج تخطي الإعلانات أو الاستحواذ المباشر على الوجهات.
* ⏱️ **عداد تنازلي ذكي:** واجهة تفاعلية تعرض حالة الفحص والأمان، وتظهر زر الانتقال المباشر (وتفتح الرابط في نافذة جديدة) فور انتهاء الوقت.
* 📱 **تصميم متجاوب بالكامل (Fully Responsive):** متوافق مع كافة الشاشات وأجهزة الهواتف الذكية مع تخطيط أعمدة جانبية للإعلانات.
* 🌍 **دعم كامل للغة العربية (RTL):** واجهات نظيفة مصممة خصيصاً للمستخدم العربي.
